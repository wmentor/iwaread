# Agent Guidelines

## Language Policy

All documentation in this project must be written in **English**.

This includes:
- README files
- Code comments (in all programming languages)
- Commit messages
- Issue descriptions
- Documentation files (`.md` files)
- API documentation
- This file (AGENTS.md)

All code comments must be written in English, regardless of the programming language used.

English is the project's working language to ensure accessibility for all contributors and users worldwide.
